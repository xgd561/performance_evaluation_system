- 初始化：`cd backend && python ../scripts/init_db.py`（需先安装 backend 依赖）
- 数据库迁移：`python scripts/migrate_db_path.py`
- 路径统一：`python scripts/update_db_path.py`（会原地改写 backend 与 init_db 源码）
- 验收标准批量更新：`python scripts/update_acceptance.py` 与 `python scripts/fix_acceptance.py`
- 开发规范文档更新：`python scripts/update_sections_9_10.py`
- 环境校验：`bash scripts/verify_p0_01.sh` 或 `cmd scripts/verify_p0_01.bat`
- 备份：`scripts\backup.bat`；重启后端：`scripts\restart.bat`
