典型 Vue3 SPA 分层架构：
- 入口 `src/main.js` 挂载 App、Pinia、Router、ElementPlus 及全局图标；根组件 `App.vue` 通过 `<router-view>` 渲染页面。
- 路由集中定义于 `src/router/index.js`，使用懒加载 `import()` 拆分代码，并通过 `meta.roles` 数组声明角色白名单，由 `beforeEachGuard` 在导航守卫中校验当前 `authStore.role`，未登录重定向 `/login`，无权限重定向 `/403`。
- API 层位于 `src/api/`，每个业务域一个文件（auth/cycles/scores/appeals/distribution/interviews/kpi-templates 等），统一通过 `src/api/request.js` 封装的 axios 实例发起请求；该实例在请求拦截器中从 localStorage 读取 `pes_access_token` 并注入 `Authorization: Bearer` 头，响应拦截器统一处理 `code !== 0` 的业务错误与 HTTP 401 自动清 token 跳转登录。
- 状态管理使用 Pinia（`src/stores/auth.js`、`app.js`），token 与用户信息持久化到 localStorage 的 `pes_access_token` / `pes_user_info`。
- 视图按业务域分目录 `src/views/<domain>/`（如 appeal、approval-workbench、cycles、score-sheet、kpi-adjustment 等），公共布局由 `components/Layout.vue` + `AppHeader` + `AppSidebar` + `BreadcrumbNav` + `PageContainer` 组合提供。
- 样式集中在 `src/styles/`，变量走 CSS 自定义属性；图表使用 ECharts + vue-echarts。
- 测试分层：单元/组件测试用 Vitest + jsdom（`tests/unit`、`tests/views`、`tests/components`、`tests/stores`、`tests/router`），E2E 用 Playwright（`tests/e2e/*.spec.ts`），分别由 `vitest.config.js` 与 `playwright.config.ts` 配置。
- 开发服务器通过 Vite proxy 将 `/api` 转发至后端 `http://localhost:8000`，生产环境可通过 `VITE_API_BASE_URL` 环境变量覆盖 baseURL。
