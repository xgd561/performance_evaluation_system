- API 调用统一通过 `src/api/request.js` 导出的 axios 实例，禁止在业务文件中直接 new axios()。
- 路由权限通过 `meta.roles` 数组声明所需角色，由 `beforeEachGuard` 校验当前 `authStore.role` 是否包含，不匹配时重定向到 `/403`。
- 认证令牌以 `pes_access_token` 键名存入 localStorage，并在请求拦截器中自动附加为 `Authorization: Bearer <token>`。
- 视图组件按业务域划分到 `src/views/<domain>/` 子目录，每个域内再拆分为列表/编辑/详情等独立 `.vue` 文件。
- 异步 API 错误统一由 request 拦截器通过 `ElMessage.error` 提示，业务组件无需重复捕获 HTTP 异常。
- 测试文件与被测源码同名对应放置于 `tests/unit`、`tests/views`、`tests/components`、`tests/stores`、`tests/router` 对应位置，E2E 用例统一放在 `tests/e2e/` 下。
