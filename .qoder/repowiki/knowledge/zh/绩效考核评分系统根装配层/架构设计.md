根目录作为多子模块的编排中枢：`main.py` 通过 `sys.path.insert` 将 `backend/` 加入路径并直接 `from app.main import app`，是 uvicorn 启动后端的唯一入口；`restart-services.bat` 同时拉起 `backend`（uvicorn 8000）与 `frontend`（Vite 3000），构成 Windows 下的双进程开发环境；`tmp_gen.py` 是前端脚手架生成器，按固定模板在 `frontend/src/` 下写出路由、Pinia store、axios 拦截器及各业务 API 客户端，约定前端以 `/api` 为 baseURL 调用后端 REST 接口；`logs/` 集中存放 pytest 基线与当前运行输出，供 test_suite 做回归比对；`bak.md` 承载 PRD 与 Story 分解，是 docs_and_prd 与 scripts_and_tools 中自动化更新流程的权威来源。各子模块之间不直接互相 import，仅通过 HTTP REST（前端→后端）、数据库（后端持久化）以及 PRD 文档进行契约式协作。
