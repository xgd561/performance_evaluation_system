- 脚本通过 `os.path.dirname(os.path.abspath(__file__))` 向上推导 `PROJECT_ROOT`，再拼接 `backend/`、`data/db/`、`backups/` 等相对路径，避免硬编码绝对路径。
- 对 Markdown 文档的修改采用「读取全文 → 正则/字符串匹配定位目标块 → 构造新内容 → 写回」的四步模式，如 `update_acceptance.py`、`fix_acceptance.py`、`update_sections_9_10.py`。

- Windows 与 Unix 双平台脚本成对提供：`verify_p0_01.sh` 与 `verify_p0_01.bat`、`backup.bat` 与 bash 等价逻辑，保持功能对称。
