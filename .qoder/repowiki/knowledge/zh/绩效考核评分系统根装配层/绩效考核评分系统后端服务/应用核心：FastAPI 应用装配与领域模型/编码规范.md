- ORM 模型统一继承 declarative_base，使用 __tablename__ 显式命名表，主键 id 采用 Integer + autoincrement + index，时间字段默认 datetime.utcnow，JSON 字段使用 JSON 类型存储配置快照。
- Pydantic DTO 按 Create/Update/Out 三态拆分，Out 类通过 class Config: from_attributes = True 直接映射 SQLAlchemy 对象。
- 复杂业务约束通过 Pydantic v2 的 @field_validator 与 @model_validator(mode='after') 集中声明（如 KPI 权重总和=100、等级区间连续不重叠、截止时间递增顺序）。
- 数据库访问统一通过 database.get_db() 生成器依赖注入，避免在路由或 service 中直接持有 Session。
- 对外 API 统一返回 {code, message, data} 结构，HTTPException 与 RequestValidationError 被 main.py 中的全局 exception_handler 转换为该格式。
