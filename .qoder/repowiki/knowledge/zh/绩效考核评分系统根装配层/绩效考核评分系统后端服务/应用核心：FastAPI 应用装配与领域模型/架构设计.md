模块按职责划分为四个层次，依赖方向单向向下：
- 应用装配层（main.py）：创建 FastAPI 实例，注册 CORS、AuditLogMiddleware 与全局异常处理器；通过 APIRouter(prefix="/api/v1") 聚合 auth、employees、departments、cycles、kpi_templates、config、dashboard、appeals、scores、approvals、interviews、peers、logs、notifications 等子路由，并为测试兼容同时挂载无前缀的 direct_api。
- 基础设施层（database.py）：基于 SQLAlchemy 创建 SQLite engine（文件位于项目根 data/db/performance_evaluation.db），暴露 SessionLocal、get_db() 生成器与 init_db() 建表函数。
- 领域模型层（models.py）：以 declarative_base 定义 Department / Position / Employee / User / AssessmentCycle / KpiTemplate / AssessmentRecord / ScoreDetail / ApprovalRecord / CycleEmployee / PeerReviewer / OperationLog / AppealRecord / InterviewRecord / SystemConfig / ScoreDraft / Notification / PeerReviewTask 等 ORM 实体，使用 ForeignKey + relationship 表达组织与考核流程关系。
- 接口契约层（schemas.py）：用 Pydantic v2 BaseModel 定义 Create/Update/Out 三态 DTO，配合 field_validator / model_validator 实现权重求和、区间连续性、截止时间顺序等业务校验。
- 依赖注入层（dependencies.py）：在 app.auth.get_current_user / require_role 之上封装 get_current_active_user，统一复用 get_db 会话依赖。
启动阶段通过 @app.on_event("startup") 执行 init_db → _migrate_db（SQLite ALTER TABLE 增量迁移）→ 按 username 幂等 seed admin/hr/mgr/emp/peer/testuser 等测试账户。
