- 所有端点统一通过 `Depends(get_db)` 注入 SQLAlchemy Session，并通过 `Depends(require_role(...))` 或 `Depends(get_current_user)` 进行鉴权。
- 对 manager/peer/employee 等受限角色的数据访问在 handler 内显式校验（如比较 `user.employee_id`、调用 `_is_in_subordinate_chain` 或 `get_all_dept_ids`），而非依赖全局中间件。
- 导出类接口（Excel、PDF）统一通过 `StreamingResponse` + `BytesIO` 返回二进制流，并设置 `Content-Disposition: attachment` 头。
- 404 场景使用 `HTTPException(status_code=status.HTTP_404_NOT_FOUND, detail=...)` 抛出中文错误信息，403 同理用于权限拒绝。
- 查询结果中的可选日期字段在返回前用 `str(x) if x else None` 转为 ISO 字符串，避免直接暴露 datetime 对象。
