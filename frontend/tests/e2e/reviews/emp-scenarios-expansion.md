## 一、普通员工工作职责总览（PRD 来源）

| 序号 | 职责领域 | 具体工作内容 | PRD 章节 |
|------|---------|------------|---------|
| 1 | **自评** | 在考核周期自评阶段，填写工作业绩（60%）、工作能力（20%）、工作态度（20%）三个维度的得分，系统提供评分锚点说明；支持保存草稿和提交自评 | 4.3, 业务流程图 |
| 2 | **查看本人绩效** | 查看当前考核状态与进度、历史绩效趋势图（折线图）、历史考核记录列表、考核详情（含三维评分对比、KPI 明细、上级评语、申诉记录、面谈记录）、下载 PDF 绩效档案 | 4.6, 4.7 |
| 3 | **发起申诉** | 对已发布的绩效结果有异议时，选择考核记录，填写申诉理由和详细说明（≥20字），提交申诉后查看申诉历史 | 业务流程图 |

## 二、使用场景扩充清单（按模块分组）

> **图例**：✅ 已覆盖（E2E 测试通过）｜ ❌ 未覆盖（前端无此功能或测试缺失）｜ ⚠️ 部分覆盖（准入性查看，无操作验证）

### 模块 A：仪表盘与快捷操作

| 场景编号 | 场景名称 | 操作步骤 | 关键断言 | 状态 |
|---------|---------|---------|---------|------|
| A-1 | 查看仪表盘员工专属统计 | 登录 → 进入仪表盘 → 查看统计卡片 | 考核记录、待自评、当前考核、当前状态卡片可见 | ✅ 已覆盖 |
| A-2 | 验证员工角色隔离 | 登录 → 检查页面元素 | 能看到"进入自评"、"查看历史绩效"、"发起申诉"；看不到"批量评分"、"进入协作评分"、管理菜单 | ✅ 已覆盖 |

### 模块 B：自评流程（员工核心高频）

| 场景编号 | 场景名称 | 操作步骤 | 关键断言 | 状态 |
|---------|---------|---------|---------|------|
| B-1 | 进入自评页面 | 登录 → 点击"进入自评"或跳转 `/self-assessment` | 页面标题"自评"、考核信息、维度自评区域、提交按钮可见 | ✅ 已覆盖 |
| B-2 | **填写并提交自评** | 登录 → 进入自评 → 填写三个维度分数 → 点击提交 → 确认弹窗 → 确定 | 提交成功提示、跳转至"我的绩效"、状态变为"待上级评" | ✅ 已覆盖 |
| B-3 | **保存自评草稿** | 登录 → 进入自评 → 填写部分分数 → 点击保存草稿 | 草稿保存成功提示、刷新后分数回显 | ✅ 已覆盖 |
| B-4 | 查看评分锚点说明 | 登录 → 进入自评 → 点击评分锚点图标（InfoFilled） | Tooltip 显示评分参考标准（如 90-100 = 优秀） | ❌ 未覆盖（需 hover 断言） |
| B-5 | 校验分数范围拦截 | 登录 → 进入自评 → 输入 -1 或 101 → 观察 | 输入框自动截断或报错提示"分数需在 0-100 之间" | ❌ 未覆盖（`el-input-number` 已内置 min/max，但需 E2E 验证） |
| B-6 | 空值提交拦截 | 登录 → 进入自评 → 不填分数 → 点击提交 | 提交按钮禁用（`canSubmit`）或报错提示 | ⚠️ 部分覆盖（仅按钮可见性断言，未验证禁用逻辑） |

| C-3 | 查看历史考核记录列表 | 登录 → 进入"我的绩效" → 查看历史记录表格 | 表格列（考核周期、总分、等级、状态、操作）可见 | ✅ 已覆盖 |
