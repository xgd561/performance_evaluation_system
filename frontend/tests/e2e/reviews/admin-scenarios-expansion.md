| 轮次 | 日期 | 通过/总计 | 主要修复内容 |
|------|------|----------|------------|
| 第一轮 | 2026-07-01 | 0/23 | 后端 `passlib` bcrypt 72 字节错误导致所有登录失败 |
| 第二轮 | 2026-07-01 | 21/23 | 修复 bcrypt 后登录正常；日期选择器 `.el-date-picker` 定位错误；日历浮层遮挡"确定"按钮 |
| 第三轮 | 2026-07-01 | 22/23 | 日期选择器改为 `getByRole('gridcell')` 点击；部门管理改为 `serial` 串行；删除部门改为行数比较 |
| 第四轮 | 2026-07-01 | 23/23 | KPI 模板编辑权重断言加 `{ exact: true }` 避免 `uniqueId` 尾号巧合匹配 |

### 关键修复技术点

1. **bcrypt 兼容性**：`passlib` 与 `bcrypt` 4.x+ 在初始化时存在已知冲突，改用 `bcrypt` 原生 API 替代。
2. **Element Plus 日期选择器**：`el-date-picker` 的 `type="daterange"` 直接 `fill` 输入框无法触发 v-model，需点击日历 `gridcell` 完成日期选择。
3. **Playwright 严格模式**：`getByText('35')` 因 `uniqueId()` 随机尾号巧合（如 `指标-e2e-...-35`）导致 strict mode violation，需使用 `{ exact: true }`。
4. **串行测试**：`test.describe.serial` 用于数据依赖链（新增 → 编辑 → 删除），避免并行 worker 状态冲突。
5. **数据残留容错**：删除断言不应使用 `not.toBeVisible()`（历史测试数据残留会导致失败），应使用删除前后行数比较（`countAfter < countBefore`）。
