## 一、Admin 工作职责清单（PRD 来源）

根据 `PRD_绩效考核评分系统_v1.0.md`，Admin 的 6 大职责领域、18 项具体工作：

| 编号 | 职责领域 | 具体工作内容 |
|------|---------|------------|
| A1 | **系统配置** | 配置考核周期（名称、起止时间、各阶段截止时间、类型） |
| A2 | **系统配置** | 配置岗位 KPI 模板（指标名称、权重、目标值、评分标准、计分方式） |
| A3 | **系统配置** | 配置维度权重与评分人权重（自评/上级评/协作评占比） |
| A4 | **系统配置** | 配置绩效等级规则（A/B/C/D 分数区间、强制分布比例上限） |
| A5 | **系统配置** | 配置小部门豁免规则（≤5 人部门是否参与强制分布） |
| A6 | **系统配置** | 配置审批链（直属上级 → 部门负责人 → HR 负责人） |
| A7 | **组织管理** | 员工管理（增删改查） |
| A8 | **组织管理** | 员工批量导入（Excel 上传、预览、校验、确认导入） |
| A9 | **组织管理** | 部门管理（增删改查、树形结构、拖拽排序） |
| A10 | **组织管理** | 岗位管理（增删改查） |
| A11 | **数据治理** | 查看全公司绩效汇总与报表 |
| A12 | **数据治理** | 报表导出（Excel / PDF） |
| A13 | **数据治理** | 已归档数据解冻修改 |
| A14 | **强制分布特批** | 作为三级特批最后一级（总经理/系统管理员）处理特批申请 |
| A15 | **权限与运维** | 角色权限分配 |
| A16 | **权限与运维** | 系统冷启动初始化（创建管理员账号） |
| A17 | **权限与运维** | 取消考核（任意活跃状态 → cancelled） |
| A18 | **权限与运维** | 操作日志审计查询 |

## 四、场景优先级建议（实现顺序）

| 优先级 | 场景编号 | 场景名称 | 理由 |
|--------|---------|---------|------|
| **P0** | S04 | 修改等级规则并保存 | 核心配置，直接影响绩效计算逻辑 |
| **P0** | S05 | 修改维度权重并保存 | 核心配置，P1-15 曾修复 Tab 标签混淆，需回归验证 |
| **P0** | S10 | 新增员工完整流程 | Admin 最高频操作，当前完全缺失 |
| **P1** | S06 | 修改审批链并保存 | 影响审批流程，需确保前后端一致 |
| **P1** | S11 | 编辑员工信息 | 员工管理日常操作 |
| **P1** | S13 | Excel 批量导入 | PRD 明确要求，但实现复杂度高（需准备测试 Excel） |
| **P1** | S23 | 创建考核周期 | 系统运行的起点，需验证表单校验和日期逻辑 |
| **P2** | S18 | 树形展开/折叠 | 有历史债务（pytest.skip 标记），但优先级相对较低 |
| **P2** | S19 | 拖拽排序 | 交互复杂，需要模拟拖拽事件 |
| **P2** | S28/S29 | 强制分布特批 | 涉及多角色联动（HR → Admin），测试链路长 |
| **P3** | S32 | 系统冷启动 | 属于边缘场景，通常只在系统初始化时触发 |

## 五、审核要点

请重点检查以下 3 项：

1. **职责完整性**：18 项职责是否有遗漏？是否有 PRD 中提到的 Admin 工作未被覆盖？
2. **场景合理性**：32 个场景是否过多或过少？是否有可以合并或拆分的场景？
3. **优先级调整**：P0/P1/P2/P3 的划分是否符合实际业务优先级？是否有场景应该上调或下调优先级？
