## 用例编号规则

```
TC-{模块}-{序号}

模块缩写:
  AUTH = 认证模块
  EMP  = 员工管理
  DEPT = 部门岗位管理
  CYC  = 考核周期管理
  SCR  = 评分管理
  APP  = 审批流程
  INT  = 绩效面谈
  APL  = 申诉管理
  PEER = 协作评分人管理
  KPI  = KPI模板管理
  RPT  = 报表分析
  CFG  = 系统配置
  LOG  = 审计日志
  SEC  = 安全测试
  PERF = 性能测试
```
